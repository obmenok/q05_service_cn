集成制动控制模块（IBCU）

拆卸

  1. 整车下电后断开蓄电池负极线束。参考 蓄电池总成

  2. 排放储液罐内的制动液。

    1. 取下远程储液罐盖。

    2. 使用一适当干净的塑料管，一端接上制动器排气嘴，另一端通入一适当的容器中。

    3. 旋松排气嘴。

    4. 保持下电，反复踩制动踏板直到储液罐中所有制动液全部排出。

    5. 旋紧排气嘴。

    注意

    为将储液罐中的所有制动液彻底排净必须对两回路都进行此步操作。

  3. 拆下制动液位传感器插头和控制模块线束接插件，拆卸过程中需避免接插件被油污污染，位置如图所示。

  4. 拆下连接软管与IBCU卡箍，拔下连接软管，再采用M10与M12开口扳手从集成制动控制模块上拆下制动油管，扭力16±2N.m/18±2N.m。

  5. 拆卸集成制动控制模块。

    1. 拆卸制动踏板与集成制动控制模块连接的球笼。

    2. 采用M13内六角套筒拆卸集成制动控制模块与制动踏板4颗固定螺母和制动踏板与车身连接的1颗螺母，扭力22±2N.m。

    3. 向外取出集成制动控制模块

安装

  1. 将集成制动控制模块放入前壁板安装孔内，预带螺母，并打紧。扭力23±2.3N.m。

  2. 用手往下按压踏板面，听到“咔”声后，预示着集成制动控制模块球头推杆与踏板球笼装配完成。

  3. 用手先将制动油管接头带紧到集成制动控制模块上，后用M10与M12开口扳手打紧，扭力16±2N.m/18±2N.m。

  4. 连接制动液位传感器插头和集成制动控制模块线束接插件。

  5. 连接蓄电池负极，参考 蓄电池总成。

  6. 如果更换了新的集成制动控制模块 ，车辆解锁上电后，首先需要使用电脑打开SDA诊断仪连接主驾下面OBD诊断口，进行刷写对应软管和软件排气

    最后再进行制动系统机械排气，参考： 制动系统排气

  7. 盖上储油壶盖。
