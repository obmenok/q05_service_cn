常见故障排查方法

故障现象

故障可能原因

排查方向建议

自动雨刮失效

1. 整车电压不足或电压过高。

2. 系统线束故障。

3. 开关信号失效。

4. 传感器未正确安装。

5. 雨刮故障。

6. 传感器故障。

1. 排查整车电压是否正常。

2. 排查整个系统线束是否有问题、插件连接是否正常。

3. 排查中控大屏、区域控制器区域是否正常。

4. 检查传感器是否装配正常。

5. 排查雨刮问题。

6. 更换传感器。

1. 整车电压不足或电压过高。

2. 系统线束故障。

3 开关信号失效。

4. 传感器未正确安装。

5. 车灯故障。

6. 传感器故障。

1. 排查整车电压是否正常。

2. 排查整个系统线束是否有问题、插件连接是否正常。

3. 排查中控大屏、区域控制器区域是否正常。

4. 检查传感器是否装配正常。

5. 排查车灯问题。

6. 更换传感器。
